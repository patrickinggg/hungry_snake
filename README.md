# 贪吃蛇游戏

一个使用 Python 和 Pygame 开发的经典贪吃蛇游戏。

## 功能特性

- 开始界面：显示游戏标题、难度选择和最高分记录
- 三种难度模式：EASY（简单）、NORMAL（中等）、HARD（困难）
- 实时分数和速度显示
- 暂停功能：游戏中按空格键或 ESC 暂停
- 最高分记录：自动保存到本地文件
- 游戏结束界面：显示最终得分，支持重新开始或返回主菜单
- 渐变色蛇身：头部深蓝，身体渐变到浅蓝
- 食物发光动画效果
- 纯图形绘制：无需字体文件，像素风格数字和字母显示

## 安装说明

### 系统要求

- Python 3.6 或更高版本
- Pygame 库

### 安装步骤

1. 确保已安装 Python 3.6+

```bash
python --version
```

2. 安装 Pygame

```bash
pip install pygame
```

3. 克隆或下载本项目

```bash
git clone <repository-url>
cd hungry_snake
```

## 运行游戏

```bash
python snake_game.py
```

## 操作说明

### 开始界面

| 按键 | 功能 |
|------|------|
| ← / → | 选择难度 |
| 空格 / 回车 | 开始游戏 |
| ESC / Q | 退出游戏 |

### 游戏中

| 按键 | 功能 |
|------|------|
| ↑ / ↓ / ← / → | 控制蛇移动方向 |
| 空格 / ESC | 暂停/继续 |

### 游戏结束

| 按键 | 功能 |
|------|------|
| ↑ / ↓ 或 W / S | 选择选项 |
| 回车 | 确认选项 |
| ESC | 返回主菜单 |

## 游戏规则

1. 控制蛇移动，吃掉红色食物
2. 每吃一个食物，蛇身增长一节，得分 +10
3. 随着得分增加，蛇的移动速度会逐渐加快
4. 撞到墙壁或自己的身体，游戏结束
5. 最高分会自动保存

## 难度设置

| 难度 | 初始速度 | 速度增长率 | 最高速度 |
|------|----------|------------|----------|
| EASY | 8 | 3% | 18 |
| NORMAL | 12 | 5% | 25 |
| HARD | 16 | 8% | 35 |

## 技术说明

- 使用 Pygame 处理图形渲染和用户输入
- 基于网格系统管理蛇和食物的位置
- 使用帧率控制实现平滑移动
- 使用文件 I/O 保存最高分记录

## 开发环境

- Python 3.x
- Pygame 2.x
